# FAME-X

An agency portfolio web application built with Next.js, TypeScript, Tailwind CSS, Zustand, and Supabase, featuring an arcade-inspired aesthetic and interactive cursor-tracking elements.

**Live Demo:** `https://fame-x-two.vercel.app/`



## Key Features

- **Arcade-Inspired Portfolio Showcase:** Clean dark-themed presentation tailored for creative and digital agency work.
- **Interactive Motion & Cursor Tracking:** Engaging UI interactions including cursor-tracking characters and dynamic visual feedback.
- **State Management with Zustand:** Predictable client state handling across interactive sections and UI states.
- **Supabase Integration:** Backend persistence and data handling for agency content and requests.
- **Responsive Layout:** Adapts smoothly across desktop and mobile viewports.

## Tech Stack

- **Framework:** Next.js (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **State Management:** Zustand
- **Backend / Database:** Supabase
